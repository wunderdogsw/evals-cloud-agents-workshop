PASS when ALL of these hold:
1. The rationale names the specific item or service from the invoice line (not just the category).
2. The rationale is consistent with the chosen cost code — it does not argue for a different code.
3. If the cost code is 9000, the rationale says what information is missing.
4. The rationale does not invent facts that are not in the line (project names, quantities, locations).
5. It is at most two sentences.

FAIL otherwise. Do not judge whether the cost code itself is correct — another grader does that.
